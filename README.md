## Maintaining this branch

Check out `docs/evaluation-reports` to add or replace approved documents. This
branch contains documents only and is not intended to be merged into `main`.
It has its own history so generated PDFs do not enter the application checkout.

Review PDFs before publication: remove credentials, tokens, private URLs,
personal location coordinates, reference photos, and biometric data. Proposal
and design documents may describe earlier plans; they do not establish what
the current source implements. Date and version updated reports clearly.
